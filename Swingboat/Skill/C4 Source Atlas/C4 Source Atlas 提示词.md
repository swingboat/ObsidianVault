$build-c4-source-atlas

请把当前工作区作为目标仓库，为第一次接触这个项目、准备参与开发的工程师生成一份 C4 Source Atlas。

我的目标是在较短时间内理解：

1. 项目解决什么问题，用户和外部系统是谁；
2. Context、Container、关键 Component 和必要的 Deployment 结构；
3. 依赖分层，以及核心模块之间允许的依赖方向；
4. 3–5 条最重要的端到端运行路径，包括入口、核心逻辑、数据访问、异步处理、失败分支和相关测试；
5. 最重要对象、任务或连接的生命周期与状态转换；
6. 配置、持久化、鉴权、错误、并发、可观测性和扩展机制等横切关注点；
7. 这个项目最有特色的 3–5 个设计选择，以及它们的收益和代价；
8. 新开发者最值得优先阅读的源码文件、测试和推荐阅读顺序。

所有架构结论必须链接到实际源码或测试，并区分 verified、inferred 和 unknown。优先使用统一 typed IR 生成架构图、工作流、时序图、数据流和生命周期图。

最终生成一份中英双语、单文件、自包含的 HTML Atlas，默认中文，保存在 output/。完成前运行全部 IR、几何和 HTML 验证，并在浏览器中检查桌面端、窄屏、语言切换和图表放大功能。发现问题请直接修复，直到验证通过。
