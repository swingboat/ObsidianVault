## 5. 关键算法与实现

本片没有讲解知识，以下全部是**制作视频时用到的算法**。

### 5.1 总体数据流：「时间 → 顶点」的纯函数 + PC2 缓存

- 纸群和主角页都写成「时间 t → 全部顶点」的纯函数。`build_scene.py` 调用时，先用 NumPy 逐帧算好，再写成 PC2 文件。
  - PC2 文件头：`POINTCACHE2\0` + `<iiffi`（版本、点数、起始帧、采样率、帧数），见 `scene/common.py:162-169`。
  - 写好后用 Mesh Cache 修改器回放，`interpolation = "LINEAR"`（`:172-179`）。
- 拓扑保持不变：每页纸 6 个顶点（沿长边 3 行 × 沿宽边 2 列），2 个四边形面。纸群共 16000 页，即 96k 顶点。
  - 缓存帧为 72–241，比镜头 2 前后各多 1 帧，给运动模糊用。
- 好处：
  - Blender 会在子帧之间线性插值顶点，所以 Cycles 和 EEVEE 都能直接渲染形变运动模糊（shutter 0.5）。
  - 渲染时不需要再运行模拟，所以可以断点续渲，结果也完全可复现（rng seed 固定为 7）。
- 代价：设计稿估算 PC2 文件约 200 MB，需要先跑完 `build_scene.py` 才能渲染。实际大小在构建日志里打印（`[swarm] ... cache=…MB`），但日志已被清理，实际值**未记录**。
- 纸群顺带输出每帧的统计：平均速度、成形比例、重心。写入 `build/events.json`，供音频合成使用（`scene/swarm.py:197-206`）。

### 5.2 主角页：沿宽度积分角度得到卷曲形状

页面剖面的角度 θ 是宽度坐标 w 的函数。从书脊开始逐段累加 `(cos θ, sin θ)·dw`，就得到弯曲的纸面，而且纸面不会被拉伸（`scene/hero_page.py:28-56`）：

```python
# 摘录 scene/hero_page.py:36-48（精简）
rest  = arctan(d block_z / d d)               # 静止时贴合书页块的弧面
lift  = smooth((t-0.6)/0.3); a = smooth((t-0.6)/1.0)
alpha = radians(75)*a; curl = 0.3 + 1.1*a; twist = 0.5*a
if t > 1.6: curl += 0.35*sin(2π·2.5·τ)…; twist += 0.25*sin(2π·1.7·τ+1)
th = rest*(1-lift) + lift*(alpha + curl*ww + twist*(0.5-yy)*ww)
x = cumsum(cos(th)*dw); z = cumsum(sin(th)*dw)
```

- 网格为 16×10 个顶点；页面宽 0.15 m、长 0.22 m（`props.PAGE_W/PAGE_L`）；缓存帧为 0–73，共 74 帧。
- 脱离书脊后（τ = t − 1.6），先旋转 `Rz(0.35τ)·Ry(−(0.6τ + 0.3τ²))`，再平移 `(−0.02, 0.10, 0.06)·τ + ½·(0, 0.40, 0.14)·τ²`。
  - 设计稿中的 v0、a 与代码不同，以代码为准。
- 主角页单独使用 `paper_mat("paper_hero", translucent=0.12)`。原因是检查点 1 发现背光透出的颗粒噪点过多，所以把透光比例降低了。
- `build()` 返回每帧的页面重心，用作 Cam1 对焦空物体的目标位置。

### 5.3 纸群：固定槽位的「流管」，没有用粒子系统或 boids

这部分沿用参考帖的思路：每页纸在队伍里有自己的位置，沿着路线飞行。实现上不做群体交互，也不做碰撞，每页纸的位置都直接由解析公式算出（`scene/swarm.py:120-174`）。

1. **每页的固定属性**（`Flock.__init__`，rng seed 7）
   - 队列序号 `u`：排序后的均匀分布，0 为排头，1 为排尾。
   - 截面槽位 `(r = √U, θ)`：在圆盘截面上均匀分布。
   - 散页标记：占 5%。
   - 6 组随机相位；翻滚角速度 ±2–6 rad/s；随机摆动轴；折弯频率 5–9。
   - 飞往鲸身时的弧线偏移 `arc`：长度 0.3–1.5 m，方向偏上。
   - 贴图象限 `cell`：0–3，对应 2×2 文字图集中的一格。
2. **中心线 C(s)**（`path()`）
   - 入口段是三次贝塞尔曲线，控制点为 `BEZ = [(−9.5, 11.2, 7.2), (−5.5, 11.6, 6.4), J − 5·E2 + (0, 0, 0.3), J]`。曲线先采样 400 个点，再按弧长重参数化（`np.interp`）。
   - s < 0 的部分沿起点切线延伸到窗外。
   - s > LB（入口段弧长）后进入竖直回环：`CV + R·(cos(a)·E1 + sin(a)·E2)`，`a = (s − LB)/R`。回环中心 `CV = (0.5, 15, 6)`；`E1` 是后仰 20° 的「下」方向，`E2 = +X`。
   - 回环半径 R 先在弧长上用 `smooth((s − LB)/8)` 渐变，同时随时间按 `ring_radius(t) = 4 − 1.2·smooth((t − 2.2)/1.8)` 收紧。这样入口段和回环的衔接处始终连续，纸页不会瞬移。散页的半径再乘 1.4。
3. **每页的弧长位置**：`s_i(t) = 6·(t + 0.3 − 3·u_i)`。排头在 t = −0.3 s 时刚好进窗，整条队伍长 18 m（6 m/s × 3 s）。
4. **截面偏移**：`rt = (0.6 + 0.6·入环程度)·√sin(π·u) + 0.15`，所以纸流头尾细、中间粗；入环后截面变粗。截面局部坐标轴为 `N = T × up`、`B = N × T`。
5. **噪声**
   - 每页自身的扰动：`0.2·sin(ω·t + φ)`，三个轴各一组。
   - 群体波：3 组 `0.5·sin(k·p + w·t)·d`，形成椋鸟群那样的整体波浪。
   - 散页在局部 t > 3.6 s 后以 0.15 m/s 的速度下沉。
6. **聚形插值**
   - 进度：`e = smoother((t − tc)/1.1)`，散页的 e 恒为 0。
   - 位置：`pos = flow·(1 − e) + whale·e + sin(π·e)·arc`。中间加了一段弧线偏移，所以纸页沿弧线飞向目标，而不是走直线。
   - 朝向：在「飞行四元数」和「鲸身目标四元数」之间做 slerp。
     - 飞行四元数 = 流向坐标系 × 绕页长轴的翻滚 × 随机轴上 0.6 rad 的摆动。
     - 目标四元数 = 由鲸身切线和法向构成的坐标系，再叠加 0.14 rad 的颤动。
   - 折弯：中间一行顶点的 z 值 = `0.035·sin(ω_flap·t + φ)·(1 − 0.85e) + 0.008`。纸页贴到鲸身上以后几乎不再折弯。
7. **向量化四元数工具**：`q_axis`、`q_mul`、`q_from_frame`（由矩阵转四元数，用 `np.select` 分 4 种情况处理）、`q_slerp`、`q_rotate`（`:24-80`）。整群 16000 页一次算完，没有 Python 循环逐页处理。

```python
# 摘录 scene/swarm.py:151-167（核心插值）
s = V * (t + 0.3 - 3.0 * self.u)
c, tan = path(s, t, self.rscale)
...
e = np.where(self.stray, 0.0, C.smoother((t - self.tc) / 1.1))
wp, wn, wt = whale.pose(self.tg, t)
pos = flow * (1 - e)[:, None] + wp * e[:, None] + (np.sin(math.pi * e))[:, None] * self.arc
```

**效果：** 纸流像一条河，截面上有体积，整体有波动；纸页从鲸头到尾鳍依次到位，可以看到鲸被一笔一笔「画」出来。

**限制：**

- 纸页之间没有避碰，鲸身上会有穿插和叠片。
- 聚形顺序只由鲸身坐标 s 决定，和纸页当前离目标多远无关，所以有的纸页要飞很长距离。这一点是对代码的推断，没有经过视觉核对。

### 5.4 鲸：参数化点云 + 尾部波动（`scene/whale.py`）

- 局部坐标中 +x 指向头部，体长 L = 9 m。
- **身体半径**：`r(s) = 1.2·s^0.5·(1 − s)^0.85/0.41 + 0.1·s`，s 是从头（0）到尾（1）的身体坐标。
  - 截面为椭圆，竖向取 0.85r；腹部（z < 0）乘 0.8；头部背面略压低（`:18-27`）。
  - 设计稿的公式是 `1.3·s^0.4·(1 − s)^1.2/0.406`，代码改成了现在的形式（「流线型」修订）。
- **采样数量**：身体 78%、胸鳍 10%、背鳍 2%、尾鳍其余约 10%。
  - 身体按半径做拒绝采样，使面积大致均匀。
  - 每个点再沿法向随机偏移 ±0.06 m，让纸页叠出类似鳞片的厚度。
- **胸鳍**：根部在 s = 0.3，向外下方伸出 3 m，宽度从 0.55 m 收窄到 0.1 m。
  - `a ∈ [0.12, 1]`：去掉根部 12%，因为那一段会埋进身体里。
  - 鳍上纸页的法向统一朝向镜头一侧（`:51-64`）。这是检查点 1 后针对「鲸背暗斑」做的修正。
- **尾鳍**：翼展 ±1.7 m，弦长约 0.9 m，前缘后掠（`x_le − 0.6·|y|^1.5`），法向随机朝上或朝下（`:77-90`）。
- **法向散布**：法向 += 切向 ±0.5 + 副法向 ±0.6，再绕法向随机扭转 ±25°（`:108-116`）。这是为了避免鲸看起来像「一块暗色实体」，见 `prompt.md` 步骤 1。
- **世界姿态**
  - 偏航 −25°、俯仰 +8°、**侧滚 −30°**（让尾鳍展开，便于看清，`:14`）。
  - 中心在 (0, 17, 5.2)，沿头部方向漂移 0.25 m/s。
- **游动**
  - 中心线 z 偏移 = `A(t)·s²·sin(2.2t − 3.5s)`，`A = 0.15 + 0.2·smooth((t − 4.5)/1.5)`。
  - 只有尾鳍的法向和切线会按 `arctan(dz/dx)` 跟着倾斜（`:134-151`）。

## 6. 声音与字幕

- **没有配音，也没有字幕。** 声音全部由 `audio/synth.py` 程序化合成，没有使用任何采样或模型。
  - 运行方式：用 Blender 自带的 Python（带 NumPy）执行，具体路径由 `post.sh` 在 Blender 的 macOS 默认安装目录中查找。
  - 输出：`build/audio.wav`，48 kHz、16 bit、立体声，10 s。
  - 随机种子：`RNG = default_rng(5)`。
- **音画同步方式：** 读取 `build/events.json` 中每帧的 `speed`、`formed`、`centroid`，用 `np.interp` 插值到每个采样点（`frames_to_samples`，`:57-58`）。这样纸声的响度、颗粒密度和声像都由画面里纸群的运动驱动。

| 声部 | 实现 | 关键参数 | 入口 |
|---|---|---|---|
| 房间底噪 | 90 Hz 中心的对数高斯带通噪声，加 0.1 Hz 起伏 | −50 dB | `audio/synth.py:62-64` |
| 掀页（镜头 1） | 2.5 kHz→4 kHz 带通噪声 × 45 Hz 颗粒（纸纤维声）+ 700 Hz 低频「翻动」颗粒；包络峰值在 1.05 s，1.6 s 有一次撕离冲击 | −20 dB；1.6–2.6 s 声像向右移到 0.7；切点前淡出 | `:67-74` |
| 纸群（镜头 2） | 28 层带通噪声（1.5–6.5 kHz，频率按对数随机）× 颗粒包络（8–25 粒/秒，速度越快越密；成形后密度降 45%，3.5 kHz 以上衰减 65%） | 响度 = `0.35 + 0.65·smooth(speed/4)`；J-cut：2.75 s 起淡入；声像 = 重心 x/7，限制在 ±0.7；−24 dB | `:77-94` |

| 混响 | 合成冲激响应：指数衰减噪声，左右声道使用独立的冲激响应 | 纸声 RT60 2.0 s，湿声 0.22；钢琴 RT60 3.2 s，湿声 0.38 | `:143-152` |

**钢琴谱**（`SCORE`，D 大调；格式为「时间 s，音高，力度」）：

- 0.4 s：D4、A4。2.0 s：F#4。3.0 s（切点）：D2 + D3。
- 4.5 / 5.5 / 6.5 s：A4 → B4 → C#5，逐级上行。
- 7.6–7.7 s：琶音式的 D 大和弦 D3 F#3 A3 D4 F#4，加高音 A5。
- 9.0 s：D5 作为余音。

**混音链**（`main()`，`:159-177`）：

1. 纸声 → 混响 → 峰值归一到 −13 dBFS。
2. 钢琴 → 混响 → 峰值归一到 −14 dBFS。
3. 两轨相加；8.6–10 s 淡出。
4. 归一到 0 dBFS，经 `tanh(0.7x)` 软限幅，再乘 −3.5 dB。

设计稿中写的是纸声 −16 dBFS，代码改为 −13。`prompt.md` 记录了改动原因：「分轨检查各段电平后，抬高聚形后的纸声底」。

**响度与检查范围：**

- `prompt.md` 记录母线为 −15.7 LUFS、峰值 −3.5 dBFS。
- 根据对话摘要，助手只做了电平和响度检查，**没有试听**。
- 本次整理没有重新测量响度。

## 8. 可复用制作经验

1. **先实测单帧，再决定方案和片长。** 前置评估时，在 Cycles 全配置下实测单帧 95 s，推算 55 秒全片要 15–30 小时，于是改成 10 秒验证片加混合引擎，实际渲染约 40 分钟。依据：对话摘要；`prompt.md`。
2. **按镜头选择渲染引擎，切点处换引擎。** 微距、透光、焦外光斑的镜头用 Cycles；大量实例加体积的广角镜头用 EEVEE。两个镜头共用同一个 `.blend` 和同一套材质，在硬切处换引擎，质感差异不容易被注意到。依据：`lights.py:119-163`；`render.sh` 的分段命令。
3. **群体动画写成「时间 → 顶点」的纯函数，烘焙成 PC2，用 Mesh Cache 回放。** 这样拓扑恒定，两个引擎都能做形变运动模糊；渲染可以断点续渲，结果可复现；同一份数据还能导出 `events.json` 驱动声音。依据：`common.py:162-179`；`swarm.py:192-213`。
4. **队伍槽位 + 路径弧长 + 依次聚形，比粒子或 boids 更好控制。** 每页纸的序号 u 决定它在队伍中的前后，截面槽位决定队伍的粗细，`tc` 公式决定成形顺序。导演意图可以直接写成公式，再加两层正弦噪声，就够自然。依据：`swarm.py:120-174`。
5. **形状要从机位方向检查。** 水平圆环从低机位看只是一团光，改成正对镜头的竖直回环后形状才看得清；鲸加了 −30° 侧滚后尾鳍才展开。依据：`plan/0b-swarm.md`；`whale.py:14`。
6. **由很多小片拼成的形体会显得暗、像实体，可以散布法向，再加只照它的补光（light linking）。** 依据：`whale.py:108-116`；`lights.py:83-97`。
7. **噪点要从源头处理。** 镜头 1 的颗粒噪点来自透光、体积雾和夹值设置：用 `hide_render` 关键帧按镜头关掉雾，降低主角页的透光比例，直接光 clamp 8。处理后单帧耗时从 38 s 降到 28 s，噪点也减少了。依据：`prompt.md` 检查点 1；`lights.py:53-55`。
8. **声音由画面统计数据驱动，用 J-cut 衔接。** 纸声的响度、颗粒密度和声像都跟随纸群的速度和重心；切点前 0.25 s 先让纸声进入。混音时先分轨检查电平，再调各声部的比例。依据：`synth.py:77-94`；`prompt.md` 步骤 3。

## 9. 复现入口

以下命令都来自项目脚本和 `prompt.md`。**列出命令不代表本次执行过。**所有命令都在 `paper-whale/` 目录下运行，需要 Blender（对话记录为 5.2.2 LTS）和 ffmpeg，并且需要 macOS Metal 才能用 Cycles GPU。

```sh
# 0. 书页贴图（只需运行一次）-> build/tex/pages.png
blender -b --factory-startup -P tools/make_textures.py

# 1. 组装场景并渲染检查静帧（检查点 1）
#    -> build/paper_whale.blend、build/events.json、build/cache/*.pc2、build/stills/
./check.sh 30,110,160,225 auto
PCT=50 SPP=16 ./check.sh 30 EEVEE          # 低清快速单帧

# 2. EEVEE 540p 全片预览（检查点 2）
PREVIEW=1 PCT=50 SPP=16 OUT=build/preview ENGINE=EEVEE ./render.sh 1 240
FRAMES=build/preview ./post.sh             # 用预览帧快速合成

# 3. 成片
ENGINE=CYCLES SPP=128 ./render.sh 1 72
ENGINE=EEVEE ./render.sh 73 240            # 默认 SPP=64
./post.sh                                  # synth.py -> audio.wav；ffmpeg -> output.mp4
```

- **需要先恢复的产物：** `build/` 已被清空，`build/tex/pages.png`、`paper_whale.blend`、PC2 缓存、`events.json`、帧序列和 `audio.wav` 都要重新生成，并且必须按 0→1→3 的顺序执行。`audio/synth.py` 依赖 `events.json`。
- **可续渲：** `render.sh` 设置了 `use_overwrite = False` 和 `use_placeholder = True`，开始前会删除大小为 0 的残帧。
- **环境耦合：**
  - `post.sh` 按 macOS 的 Blender 默认安装路径查找自带的 Python。
  - `make_textures.py` 使用 macOS 系统字体路径。
  - `lights.py` 写死了 Metal 设备。
  - 在其他平台运行时，这三处都要修改。
