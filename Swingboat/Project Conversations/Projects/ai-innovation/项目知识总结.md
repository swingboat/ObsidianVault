# ai-innovation · 项目知识总结

## 二、产品研究：把兴趣转成可验证的问题

### 八个观察维度

核心问题是：**谁在什么场景下，原来如何解决什么麻烦，产品具体改变了哪一步？**

1. 用户与付费者分别是谁。
2. 问题发生的频率、时间成本、损失或风险。
3. 原有流程：人工、表格、设备、其他软件，或者暂时忍受。
4. 核心价值：改善哪一个结果。
5. 输入 → 处理 → 输出 → 后续行动。
6. 一个具体的设计或技术选择，以及它为何有效。
7. 使用门槛：设备、数据、学习、信任、结果质量和迁移。
8. 商业与空白：谁为哪个结果付费，还有哪些假设没有验证。

会话建议优先看清问题、原来的做法、核心流程、独特设计，再迁移到自己熟悉的场景。这里的目标是形成一个能验证的最小实验，而不是每次都扩成完整创业计划。[S01-T02](会话索引.md#s01-t02)

## 三、LiDAR、图像、深度和语义是不同层

### 传感器测距离，识别模型判断“是什么”

RGB 图像保存外观；深度图保存表面深度；置信度反映观测质量；语义标签回答像素或点属于动物、草、天空或其他类别。LiDAR 不自动附带“牛”的标签，也不直接给出体重。

会话列举了 iPhone、扫地机器人、自动驾驶、无人机、专业扫描仪的用途，并区分空间扫描、激光辅助对焦和人脸深度感知。具体机型支持情况是当时的产品核对，不能从“会测距”推出“具有相同 LiDAR 功能”。[S03-T01](会话索引.md#s03-t01)、[S03-T02](会话索引.md#s03-t02)、[S03-T03](会话索引.md#s03-t03)

### ARKit 一帧有哪些输入

历史研究讨论 `capturedImage`、`sceneDepth.depthMap`、`confidenceMap`、`camera.intrinsics`、`camera.transform` 和可选时间平滑深度。颜色通常来自相机图像；深度缓冲区不能自动理解成彩色照片。尺寸、格式、对齐和坐标约定需从实际接口取得。

`high` 是置信度等级，不是“准确率 99%”。动物在动、图像有遮挡时，时间平滑和多帧处理都需要重新验证，不能只看静态场景效果。[S02-T07](会话索引.md#s02-t07)

### 算法 A：相机内参与反投影

在会话采用的针孔教学模型中，图像横向向右、纵向向下，示意相机 Z 向前：

$$
u=c_x+f_x X/Z,\quad v=c_y+f_y Y/Z
$$

反过来：

$$
X=(u-c_x)Z/f_x,\quad Y=(v-c_y)Z/f_y
$$

`f_x,f_y` 是像素单位的焦距，`c_x,c_y` 是主点。示例 `f_x=f_y=500,c_x=320,c_y=240` 时，点 `(X,Y,Z)=(0.4,0.2,2)` 投到 `(u,v)=(420,290)`。

内参必须匹配所处理图像/深度的分辨率；裁切、缩放、旋转不能只改变数组而保留错误内参。实际 ARKit 相机轴、图像方向与世界坐标的转换应遵循接口约定，不能混用教学坐标。项目中的内参实验把参数、投影和公式联动起来，但它是教学演示。[S02-T08](会话索引.md#s02-t08)、[S02-T09](会话索引.md#s02-t09)、[F08](会话索引.md#f08)

### 算法 B：由二维动物掩码取得动物点云

```text
RGB → 图像分割 → 动物掩码
掩码与深度对齐 → 保留动物位置的有效深度/置信度
匹配内参反投影 → 可见动物点云
```

分割解决归属，反投影解决坐标。被遮住的身体没有可见深度，正确的掩码也不能直接补出真实背面。不同角度会改变可观测部位；会话没有得到 Scanabull 按角度报告的公斤误差表，不能编造“转 30° 增加多少误差”。[S02-T07](会话索引.md#s02-t07)、[S02-T10](会话索引.md#s02-t10)

### 算法 C：RANSAC 与 DBSCAN 的正确位置

RANSAC 反复抽样拟合平面，以内点数量寻找支持较多的平面；得到的平面还需结合方向、位置与覆盖判断是不是地面。DBSCAN 依据邻域与密度把点连成群，它理解的是空间连续性，不是动物语义。

主要失败模式包括墙比地面占比大、草地不平、牛蹄被地面阈值误删、牛与围栏通过少量点连通、深度缺口把一头牛拆成多群。因此几何规则可以做预处理或受约束基线，不能默认当作可靠动物分割。[S02-T11](会话索引.md#s02-t11)

### 算法 D：直接学习三维语义

输入一帧 `N×(XYZ+可选颜色/置信度)`，输出 N 个类别/分数，依靠邻域或全局几何上下文判断动物点。分割训练需要点级标签，体重回归需要动物数据与真实秤重配对，两种监督不能互相替代。

PointNet/PointNet++、点云 Transformer 是研究路线；Scanabull 的公开标注说明和历史开发帖子提供过采样、嵌入、8 个 Transformer 块、二分类等线索。这不是当前生产架构的完整公开证明，也不是本项目已经训练的模型。SageMaker 标注材料的标题同样不足以确定整个生产云架构。[S02-T02](会话索引.md#s02-t02)、[S02-T12](会话索引.md#s02-t12)、[S02-T13](会话索引.md#s02-t13)

## 四、两个训练实验要分开看

### 1. 浏览器小模型：真实参数更新，合成数据

`scanabull-training-lab.html` 用 JavaScript 实现教学训练循环：前向预测 → 损失 → 反向传播 → Adam 更新。分割 MLP 为 `3→16→8→2`，回归 MLP 为 `3→12→8→1`；隐藏激活 ReLU，输出分别是类别概率与连续值，标准化统计量取自训练集。[S02-T06](会话索引.md#s02-t06)、[F07](会话索引.md#f07)

分割样本由合成动物与固定背景规则产生，小 MLP 逐点看坐标，没有真实点云噪声、邻域结构或 Transformer。会话所说“可以训练”指参数确实可更新，不证明能在真实牧场估重。

**本次静态核对发现一处复现细节：**页面说明展示的合成重量简式是 `100+70×L×H×W+噪声`，但当前 `generateReg` 实现还包含 `90×L+55×H+80×W`。复现合成数据应以实际函数为准；这不是牛体生理公式。本轮记录该差异，没有修改原页面。[F07](会话索引.md#f07)

### 2. 猫狗分割：真实图像、人工标签与 Tiny U-Net

数据为 Oxford-IIIT Pet：RGB 图片及三值人工 trimap。原值 `1=动物、2=背景、3=边界` 映射成 `0=背景、1=动物、2=边界`。这是像素级三类分割，不能理解为猫/狗二分类，更不能等同牛的个体识别或估重。[S02-T14](会话索引.md#s02-t14)、[S02-T16](会话索引.md#s02-t16)、[F01](会话索引.md#f01)、[F02](会话索引.md#f02)

预处理顺序：

```text
读取 RGB → 双线性缩放
读取 trimap → 最近邻缩放
训练时同步随机翻转图像与标签
图像 HWC→CHW、float32、除以 255
标签映射为 int64 类别
DataLoader 堆叠成 NCHW，只有训练时 shuffle
```

Tiny U-Net 的编码通道为 `base、2base、4base`，桥接为 `8base`；三次 `MaxPool2d(2)` 下采样，解码时双线性上采样，与对应编码特征沿通道拼接，再卷积。块中有 3×3 Conv、GroupNorm(4)、ReLU，最后 1×1 Conv 输出 3 类。原参数 base=16 时通道依次为 16、32、64、128。[F01](会话索引.md#f01)

损失采用三类交叉熵，加上动物类 soft Dice 的补项：

$$
L=CE+0.5(1-Dice_{soft,pet})
$$

代码中的 soft Dice 对每张图在空间维求和，并在分子、分母加入平滑项 1。优化器是 AdamW；验证阶段不求梯度、不更新参数。每轮按验证动物 IoU 选择最佳 checkpoint，最后载入最佳轮次再评估独立测试。[F01](会话索引.md#f01)

## 五、学习问答中形成的关键知识

### RGB 归一化、零均值与标准化

8 位通道有 0–255 共 256 个值，除以 255 改变表示尺度；例如 50/255≈0.196。它把值放到 0–1，**不保证数据以 0 为中心**。标准化 `(x-均值)/标准差` 是另一件事；模型输入也不都要求在 0–1。训练与预测的表示、数值范围和处理顺序要一致。[S04-T01](会话索引.md#s04-t01)、[S04-T02](会话索引.md#s04-t02)、[S04-T03](会话索引.md#s04-t03)

“1 左右是唯一最佳幅度”在会话中被纠正。输入尺度会影响梯度与学习率的配合，数值更小不自动更好。标准差描述分散尺度，方差由偏差平方平均得到；会话中的公式是总体式教学例子，不应无条件替代所有样本统计估计。[S04-T12](会话索引.md#s04-t12)、[S04-T13](会话索引.md#s04-t13)

### 图片尺寸、插值和标签语义

文件 MB 大小、图片 W×H 和模型 `--size` 不同。浏览器放大显示与重采样文件也不同；放大像素数不能恢复没拍到的细节。

双线性从四邻域按位置加权，适合可混合的连续数值。类别编号不应取平均，因此分割任务中的照片仍可用双线性，人工/预测类别图使用最近邻。把“做分割就全部最近邻”在会话中修正为按数据语义选择。[S04-T04](会话索引.md#s04-t04)～[S04-T07](会话索引.md#s04-t07)

### 卷积、ReLU、池化、感受野、张量

- 3×3 是空间覆盖，不是总权重数；卷积权重形状涉及输入、输出通道。例如 3 通道输入、16 输出的 3×3 层有 `16×3×3×3=432` 个权重，不含偏置。[S04-T09](会话索引.md#s04-t09)
- ReLU=`max(0,x)`，带来非线性；正半轴导数为 1 不等于整个深网“绝不会梯度消失”，负区会截断梯度。[S04-T10](会话索引.md#s04-t10)、[S04-T11](会话索引.md#s04-t11)
- 2×2 最大池化按每个通道保留局部最大响应，减少空间尺寸并丢失精确位置/较弱响应；它不是简单删除原照片的一半像素。[S04-T14](会话索引.md#s04-t14)
- 感受野指某特征位置受原输入多大范围影响。会话中连续 3×3 得 3、5、7 的例子有步长 1、无其他改变的条件；不能把该序列当成任意网络规则。[S04-T15](会话索引.md#s04-t15)
- 张量是多维数据表示，模型中常用 `N×C×H×W`；它不是机器学习专属概念。shuffle 改变读取顺序，图像与标签保持成对，验证/测试通常不靠打乱提升总分。[S04-T08](会话索引.md#s04-t08)、[S04-T16](会话索引.md#s04-t16)

### 评估指标与业务指标分开

$$
IoU=|P\cap G|/|P\cup G|,\quad Dice=2|P\cap G|/(|P|+|G|)
$$

分割损失、像素准确率、动物 IoU、公斤 MAE、实际业务收益是不同指标。更好的分割不自动保证准确估重；拍摄缺失、传感器噪声、品种和场地差异仍会影响后续结果。[S02-T07](会话索引.md#s02-t07)、[S02-T16](会话索引.md#s02-t16)、[F01](会话索引.md#f01)

## 七、项目内形成的最佳实践

| 做法 | 具体依据与适用条件 |
| --- | --- |
| 给研究一个问题和停止条件 | 先看演示、做一个任务，再围绕一个机制深入；适用于探索型学习，不把星数等同实用价值。[S01-T03](会话索引.md#s01-t03) |
| 给事实分层 | 公开原文、厂商陈述、自己的推断和实测分开；处理准确率、融资、客户和性能宣称时尤其重要。[S02-T01](会话索引.md#s02-t01)、[S05-T02](会话索引.md#s05-t02) |
| 用小实验拆开复杂链路 | 无 LiDAR 设备时先学公开 RGB-D、点云处理、图像分割，再考虑真实采集与部署；每阶段设一个产物。[S02-T05](会话索引.md#s02-t05) |
| 标明合成数据和真实数据 | 真参数更新不等于真实业务验证；教学模型架构、标签来源和场景假设写清。[S02-T06](会话索引.md#s02-t06)、[F07](会话索引.md#f07) |
| 保留数据与模型选择的边界 | 训练做梯度更新，验证选 checkpoint，测试用于最终衡量；按身份/场地拆分与随机按图像拆分是不同证据。[F01](会话索引.md#f01)、[F02](会话索引.md#f02) |
| 图像与标签保持配对 | 随机翻转/缩放同步，标签用最近邻并验证类别值；输入与预测采用一致预处理。[F01](会话索引.md#f01) |
| 保存可复现记录 | 固定 seed、记录版本、splits、配置、最佳轮次、训练前基线和逐类指标；可复现同一小实验不代表外部泛化。[F03](会话索引.md#f03)～[F05](会话索引.md#f05) |
| 分开检查技术产物与实际质量 | 能训练、能导出或 loss 下降，不等于边缘好、跨牧场有效或有商业价值；报告失败样例和弱类。[S02-T16](会话索引.md#s02-t16) |
| 对比业务完整流程 | 把重拍、人工复核、录入和实施计入成本，连接观察结果与最终回执。[S02-T17](会话索引.md#s02-t17) |
| 保留纠错与当前结论 | 聚类不能替代语义、归一化不是中心化、功能不自动是壁垒；旧说法失效时明确记录原因。[S02-T11](会话索引.md#s02-t11)、[S04-T03](会话索引.md#s04-t03)、[S06-T02](会话索引.md#s06-t02) |
| 页面说明与生成代码交叉核对 | 合成回归的说明简式与实际生成函数存在差异，本次如实记录；复现应指到实现而非只读示意文案。[F07](会话索引.md#f07) |
| 交互讲解围绕变量与可观察结果 | 调内参同步更新公式/投影，调遮挡观察可见点，多帧实验区分噪声与系统偏差；演示数据不替代真实验证。[S02-T04](会话索引.md#s02-t04)、[S02-T09](会话索引.md#s02-t09) |

上述是本项目经历归纳，适用条件随任务变化，不把单次结果写成普遍行业保证。
